Direction

Use the selected high-tech index: a hard-edged systems interface with switchable monochrome and cyberpunk schemes. The catalog comes before decoration; the first row should appear in a normal laptop viewport.

The selected implementation lives in Hugo templates and assets/css/high-tech.css. Hugo generates the landing, tool index, detail, and about pages into static/; catalog cards resolve to /tools/<slug>/.

  • Semantic HTML, ordinary links, no JavaScript dependency.
  • Responsive one-to-three-column grid with one keyboard stop per tool card and visible focus.
  • CSS-only catalog visuals avoid unused image assets.
  • Keep main.go unchanged: generation happens before serving.

Build contract

tools/<slug>/tooltown.yaml         # canonical tool metadata
tools/<slug>/screenshots/*         # colocated catalog assets
content/tools/_content.gotmpl      # data-to-page adapter
layouts/                           # Hugo page templates
assets/css/high-tech.css           # authored shared style
scripts/build-site                 # pinned Hugo build
static/                            # generated, checked-in output

Required fields are name, summary, and HTTPS source_url. Tool metadata may add a tagline, Markdown description, category, status, visual treatment, language, license, platforms, features, install and usage commands, and screenshots with explicit alt text. The directory name is the canonical slug.

Quality and monitoring

  • Build validation for required metadata, referenced assets, deterministic output, and stale-file cleanup.
  • Release smoke checks for generated links and served status codes.
  • Accessibility review: skip link, heading order, focus visibility, contrast, keyboard flow, 320 px width, missing images, and CSS-disabled reading order.
  • Performance: reserve image space; do not lazy-load likely above-fold images; use loading="lazy" only below the fold.
  • Primary references: HTML Standard: article, MDN: progressive enhancement, web.dev: responsive images, and web.dev: image lazy loading.
