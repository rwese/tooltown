SYS.OVERVIEW

Put directory paths on the system clipboard from a small cross-platform Go CLI.

pwd-copy resolves a directory path and sends it to the first supported clipboard command available on the system. It supports macOS and common Linux clipboard tools, with an environment-variable escape hatch for custom commands.

Capabilities

  • Copies the current directory when called without arguments.
  • Resolves a target to an absolute path.
  • Copies a target relative to the current working directory with -r.
  • Detects pbcopy, wl-copy, xclip, or xsel automatically.
  • Accepts a custom clipboard command through PWD_COPY_CLIPBOARD_COMMAND.

Install

go install github.com/rwese/pwd-copy@a3298189d8ba57a5b68112a3b1287d59ac3204b8

Usage

pwd-copy
pwd-copy .
pwd-copy -r ../another-directory
