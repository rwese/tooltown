TOOL.OVERVIEW

An agent-agnostic web search core backed by SearXNG, with every search saved as a reusable session on disk.

web-search-mcp exposes a single SearXNG-backed search core behind three surfaces: a CLI, a Model Context Protocol server, and a pi extension. Every search is persisted as an immutable session on disk and can be re-read later from any surface. An optional OpenAI-compatible LLM turns a plain query into a planned, multi-query, AI-synthesized answer with numbered source citations.

Capabilities

  • Searches through your own SearXNG instance with category, engine, language, time-range, and safesearch filters.
  • Saves every search as an immutable session on disk, re-readable from the CLI, MCP, or pi.
  • Speaks Model Context Protocol over stdio or streamable HTTP so AI agents can call the same search core.
  • Synthesizes cited AI answers with --use-ai when an OpenAI-compatible endpoint is configured.
  • Validates the full setup with --doctor, including a live probe search.

Install

npm install -g @rwese/web-search-mcp@0.6.0

Usage

export SEARXNG_URL=https://search.example.com
web-search "what is kubernetes"
web-search "fusion breakthrough" --categories news --time-range day
web-search --session cc6a54d5-what-is-kubernetes --json
web-search --doctor
