About Tooltown

A town of focused tools developed and maintained by Wes.

Tooltown is a home for the small tools I develop. Each tool has a clear job, practical documentation, and a direct link to its source.

The catalog is built with Hugo and served as static files. It requires no client-side JavaScript.
