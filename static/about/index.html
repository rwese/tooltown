About Tooltown

A small catalog of focused, independently maintained software.

Tooltown is a directory for small tools with clear jobs. Each listing is generated from metadata kept beside the tool’s screenshots and other catalog assets.

The catalog is built with Hugo and served as static files. It requires no client-side JavaScript.
